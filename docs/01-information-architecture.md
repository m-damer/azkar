## خريطة الشاشات
```
أول استخدام (3 شاشات) → الرئيسية
الرئيسية
 ├─ شريط السلسلة (أعلى)
 ├─ بحث → اقتراحات → نتائج (الكل | الأذكار | الأدعية | الآداب | لا نتائج)
 ├─ جلسات اليوم: الصباح / المساء / النوم → القارئ
 ├─ الأوراد → قائمة / ورد جديد / عدّ الورد / اكتمل
 ├─ المفضلة → قوائم المستخدم → داخل قائمة / إضافة / حفظ / حذف
 ├─ المزيد من الأذكار → تبويبات تصنيفات (تمرير أفقي) → أبواب → القارئ
 ├─ الأدعية → نفس البنية → القارئ
 └─ الآداب الجامعة (تحت الأدعية، لون رملي) → قائمة/بحث → القارئ
القارئ: بطاقة بحجم ثابت (النص يمرَّر داخلها مع الحقول الصغيرة مقدمة/فضل/تخريج/ملاحظة) + العداد + السابق/التالي + قائمة أذكار الجلسة.
  التنقل بين الأذكار: أزرار السابق/التالي **وسحب الشاشة يميناً ويساراً** (RTL: السحب لليسار = التالي). زرّا «الفضل» و«شرح مختصر» ملغيان.
التذكيرات: قائمة / اختيار الوقت / التنبيهات مغلقة
الإعدادات: حجم الخط / سلسلتي / مصادر النصوص / عن التطبيق
```
التنقل السفلي: كبسولة عائمة بعناوين ظاهرة دائماً (القرار المعتمد). عدد التبويبات النهائي يُثبَّت من شاشة `Main`.

## قواعد التصنيف
- ذكر = مرتبط بوقت أو مكان أو فعل. دعاء = طلب حاجة أو حالة.
- جلسات الرئيسية (صباح/مساء/نوم) تُسحب من أبواب بعينها (27 صباح ومساء، 28 النوم)، لا تصنيفات جديدة.
- ترتيب الأبواب داخل التصنيف = ترتيبها في الكتاب.

## قرارات محسومة
- «الآداب الجامعة» قسم رئيسي ثالث تحت الأدعية (لون SAND)؛ الملف يحتوي حالياً تصنيفاً واحداً وعنصراً واحداً، فشاشته بلا شريط تصنيفات.
- أسماء الأبواب والتصنيفات من الملف لا من التصميم.
- زرّا الفضل والشرح ملغيان من كل الشاشات؛ حقول `intro/virtue/takhrij/note` تُعرض كنص صغير داخل البطاقة.
- بطاقة القارئ بحجم ثابت والنص يمرَّر داخلها.
- التنقل بين أذكار الجلسة بالسحب أفقياً وبالأزرار.
